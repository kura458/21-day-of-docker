# Docker DataCamp Learning Journal

A 21-day learning journal documenting practical study of Docker, from container fundamentals to building and deploying a multi-container application.

The repository is organized by day, with a dedicated folder and README for each topic.

## Learning plan

- **Duration:** 21 days
- **Study plan:** Approximately 2 hours per day
- **Learning source:** DataCamp
- **Topics:** Containers, images, Dockerfiles, volumes, networking, security, image optimization, multi-stage builds, and Docker Compose

## Repository structure

Each daily folder contains a README with the topic notes and commands for that day.

## Learning objectives

By the end of this learning plan, the journal is intended to help document practical understanding of:

- Creating, running, inspecting, and managing containers
- Building and distributing Docker images
- Writing and optimizing Dockerfiles
- Managing persistent data with volumes
- Connecting containers with Docker networking
- Applying Docker security practices
- Using build cache and multi-stage builds
- Defining multi-container applications with Docker Compose

## Getting started

Clone the repository:

```bash
git clone https://github.com/kura458/21-day-of-docker.git
cd 21-day-of-docker
```

Start with the first day's notes:

[Day 01 – Docker Introduction](./01-docker-introduction/)

Follow the folders in order. Use the commands in each day's README in an environment where Docker is installed.
